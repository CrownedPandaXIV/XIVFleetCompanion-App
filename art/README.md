# Artwork

- `submarine-icon-next.webp`: the source of the submarine icon (steel-blue hull with a light outline, amber portholes and
  hatch light, transparent background), in use since the 2.x layout and themes stage: the app's `submarine.ico`
  (16 to 256 pixels, each drawn from this) and the plugin's `Data/submarine.png` (512 pixels: its picture in the
  sidebar and its icon in Dalamud's plugin list).
